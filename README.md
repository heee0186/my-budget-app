# 가계부 v3

급여(매달 17일)로 갚을 카드값을 카드별 예산 안에서 관리하는 개인 가계부.

- 화면: `index.html` 하나 (Vercel 배포). 로그인한 주인만 볼 수 있음
- 데이터: Supabase 프로젝트 2의 `gagyebu` 스키마 (`supabase/1-schema.sql`)
- 결제 기록: 폰 알림 수집기 → `money.notif_raw` → `gagyebu.payments` (자동)

## 청구월
"12월 카드값" = 12월 18·20일에 빠져나가는 돈. 카드마다 이용기간이 달라요.

| 카드 | 이용기간 | 결제일 | 통장 |
|---|---|---|---|
| 롯데 | 전월 7일 ~ 6일 | 20일 | 급여 통장 |
| 농협 | 전월 5일 ~ 4일 | 18일 | 농협 통장 |
| 삼성 | 전월 6일 ~ 5일 | 18일 | 급여 통장 |

할부는 개월 수로 나눠 각 청구월에 잡고, 2회차부터는 "할부(이미 정해진 돈)"로 따로 보여줘요.
금액은 할인 전(긁은 금액) 기준이라 실제 청구액은 조금 적을 수 있어요.
